# home-w42-eu-ideas

Ideas for devices, adapters, apps and loops for `../home-w42-eu`. See [README.md](README.md) for the index and the outline.

- One file per idea in `ideas/`, using the outline in the README. Add every new file to the README table.
- Start every idea from a person's need: name the use case it serves (`../home-w42-eu/docs/use-cases.md`), or propose a new use case there.
- Check ideas against `../home-w42-eu/docs/principles.md`.
- Mark the status and date. Say what was proved on hardware.
- Name prior art (existing open-source projects) before proposing to build something.
